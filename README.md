# Airline Performance & Customer Satisfaction Dashboard | Tableau

## Project Overview
This academic project uses Tableau to analyze airline operational performance and passenger satisfaction. The interactive dashboard provides insights into flight delays, cancellation rates, monthly delay trends, flight distance, customer feedback, and operational performance by origin city.

## Objectives
- Analyze average flight delays across different airlines.
- Track monthly flight delay trends and cancellation rates.
- Explore the relationship between flight distance and delays.
- Evaluate passenger satisfaction across different feedback categories.
- Visualize operational performance by origin city.

## Key Insights
The analysis highlights the relationship between operational performance and passenger satisfaction. Higher flight delays and cancellation rates can contribute to lower customer satisfaction.

Reducing delays, improving operational reliability, and addressing low-rated service categories can help airlines enhance passenger experiences, strengthen customer loyalty, and improve overall service quality.

## Dashboard Features
- Average Delay by Airline
- Monthly Delay Trend
- Cancellation Rate by Airline
- Distance vs. Delay Analysis
- Customer Satisfaction by Feedback Category
- Operational Performance by Origin City
